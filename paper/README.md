# Paper source

Public author version of *Adaptive-Group Process Rewards for GUI Agents*.

`main.tex` includes the author list. The double-blind submission file is not in this repository. The arXiv upload is not ready yet.

Compile from this directory:

```bash
pdflatex main
bibtex main
pdflatex main
pdflatex main
```

Prompts used by the critic are in `prompts/`. Figures are in `figures/`.
